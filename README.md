# Translation Workflow Lab

영어→한국어 번역 과정의 관찰·검증에 관한 연구 자료를 보관합니다. 장기 목적은 영어 독해력이 제한적인 한국어 화자가 AI의 작업 과정에서 유용한 읽기 방법을 배울 수 있는지 연구하는 것입니다.

## 논의 기록

[문제의식·논의 흐름·연구 질문·범위 결정](docs/discussions/2026-11-12-research-motivation-and-scope.md)

- AI 작업 과정을 사람이 학습할 수 있는가라는 출발점
- 장문 요약에서 번역을 통한 읽기 과정 연구로 좁혀진 이유
- 번역을 이해의 관찰 과제로 삼는 가설과 우회 경로 문제
- 인간·코드·협업으로 절차를 재현하는 관점
- 확정된 작업 범위와 아직 검증하지 않은 질문

## 조사 문서

[번역 워크플로우 연구 조사 및 적용안](docs/research/translation-workflow-research.md)

- 최근 번역·추론 관련 핵심 연구 8편과 출처
- 중간 산출물 기록과 기여 검증 방법
- 번역 품질·비용 비교를 위한 실험 설계
- 논문에서 확인한 내용과 자체 제안, 미검증 항목 구분

## 현재 범위

문서 저장만 완료한 상태입니다. 모델 실행, 실험 구현, math2phys 적용은 수행하지 않았습니다. 문서의 적용안은 후속 검토를 위한 제안이며 실행 승인을 뜻하지 않습니다.
