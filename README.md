# Translation Workflow Lab

영어→한국어 번역 과정의 관찰·검증에 관한 연구 자료를 보관합니다.

## 조사 문서

[번역 워크플로우 연구 조사 및 적용안](docs/research/translation-workflow-research.md)

- 최근 번역·추론 관련 핵심 연구 8편과 출처
- 중간 산출물 기록과 기여 검증 방법
- 번역 품질·비용 비교를 위한 실험 설계
- 논문에서 확인한 내용과 자체 제안, 미검증 항목 구분

## 현재 범위

문서 저장만 완료한 상태입니다. 모델 실행, 실험 구현, math2phys 적용은 수행하지 않았습니다. 문서의 적용안은 후속 검토를 위한 제안이며 실행 승인을 뜻하지 않습니다.
